A fast drop-in replacement for the reference static site generator: a single-pass Markdown renderer, a per-build slug cache, allocation-light word counting and template rendering into a shared chunk buffer, producing output identical to the reference on every case.

## Run it

```sh
node main.ts
```

The program reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes the answers to `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
